# Arista NetDevOps Labs

Hands-on networking and automation labs using Arista EOS/cEOS,
Containerlab, Ansible, and Jinja2.

## Lab Environment

- Arista cEOS
- Containerlab
- Ansible
- Jinja2
- Python
- Git
- VS Code

## Labs

| Lab | Topic | Technologies |
|-----|-------|--------------|
| 01 | Containerlab Basics | Containerlab, cEOS |
| 02 | Ansible Basics | Ansible, EOS |
| 03 | eBGP Leaf-Spine | BGP, Ansible, Jinja2 |
| 04 | Static VXLAN | VXLAN, HER, Jinja2 |
| 05 | VXLAN EVPN | BGP EVPN, VXLAN, Ansible |

## Learning Path

Containerlab
→ Arista EOS
→ Ansible
→ Jinja2
→ eBGP
→ VXLAN
→ EVPN
→ NetDevOps
